LMS Reader Agent — ตัวเชื่อมเครื่องอ่าน RFID (SID) ใน LAN กับ server บนอินเทอร์เน็ต
=====================================================================================

โปรแกรมนี้ต้องรันบน PC ที่อยู่วง LAN เดียวกับเครื่องอ่าน RFID (เช่น 192.168.1.250)
และออกอินเทอร์เน็ตได้ — PC จะต่อ "ขาออก" ไปที่ https://api.welcleankhoka.com เอง
ไม่ต้องเปิดพอร์ต / ไม่ต้องทำ VPN

ติดตั้งครั้งแรก
--------------
1) ติดตั้ง Node.js LTS (เวอร์ชัน 20 ขึ้นไป) จาก https://nodejs.org  (กด Next จนจบ)
2) แตกไฟล์ zip นี้ไว้ที่ถาวร เช่น C:\lms-reader-agent
   (อย่ารันจากในไฟล์ zip / โฟลเดอร์ Downloads ที่อาจถูกลบ)
3) ทดสอบว่า PC ต่อเครื่องอ่านได้: ดับเบิลคลิก test-reader.bat
   ใส่ IP และ Port ของเครื่องอ่าน (ดูได้ที่หน้าเว็บ "อุปกรณ์ & สัญญาณ RFID")
   ต้องขึ้น "ต่อได้" ถ้าไม่ได้ ให้เช็คสาย LAN / IP ของ PC ต้องอยู่วง 192.168.1.x
4) ดับเบิลคลิก start.bat
   - ครั้งแรกจะเปิด Notepad ไฟล์ .env ให้วาง DEVICE_TOKEN
     (token ได้จากหน้าเว็บ "อุปกรณ์ & สัญญาณ RFID" ตอนเพิ่มเครื่องอ่าน หรือกด "รีเซ็ต token")
   - บันทึก ปิด Notepad แล้วดับเบิลคลิก start.bat อีกครั้ง
   - ต้องขึ้น "เชื่อมต่อ server สำเร็จ — พร้อมรับคำสั่งสแกน"
5) ลองกดสแกนจากหน้าเว็บ — หน้าต่าง agent จะขึ้น "สั่งสแกน ..." และ "ได้ N แท็ก"

ให้รันเองทุกครั้งที่เปิดเครื่อง + รีสตาร์ทเองเมื่อล่ม (แนะนำ)
-----------------------------------------------------
- ปิดหน้าต่าง start.bat ก่อน
- คลิกขวา install-service.bat > Run as administrator
- จะติดตั้งเป็น Windows Service ชื่อ "LMS Reader Agent" รันเบื้องหลัง:
    * เปิดเครื่อง / รีสตาร์ทเครื่อง (รวมถึงหลัง Windows Update) -> ทำงานเองทันที ไม่ต้องล็อกอิน
    * โปรแกรมล่ม -> เปิดใหม่เองใน 3 วินาที
    * ตัว service หยุดผิดปกติ -> Windows สั่งเปิดใหม่ให้อีกชั้น (5 / 10 / 30 วินาที)
    * เน็ตหลุด / server ล่ม -> ต่อใหม่เองเรื่อยๆ ไม่ต้องทำอะไร
- ดูสถานะ: ดับเบิลคลิก status-service.bat (ต้องขึ้น RUNNING และ AUTO_START)
  หรือเปิด services.msc หา "LMS Reader Agent"
- สั่งรีสตาร์ทเอง: คลิกขวา restart-service.bat > Run as administrator
- ดู log: โฟลเดอร์ daemon\ (lmsreaderagent.out.log = log ของโปรแกรม)
- ถอนออก: คลิกขวา uninstall-service.bat > Run as administrator

เปลี่ยน token / แก้ค่า
---------------------
แก้ไฟล์ .env ด้วย Notepad แล้วคลิกขวา restart-service.bat > Run as administrator

ข้อควรรู้
--------
- token 1 ตัวใช้รับงานสแกนให้ "ทุกเครื่องอ่าน" ของโรงพยาบาลนั้นได้ (ถ้าอยู่ LAN เดียวกัน)
- ถ้า agent ไม่ได้เปิด กดสแกนจากเว็บจะขึ้นว่าเชื่อมต่อเครื่องอ่านไม่สำเร็จ
- หน้าอุปกรณ์บนเว็บจะเห็นเครื่องที่ใช้ token นี้เป็น ONLINE ระหว่างที่ agent ทำงาน
